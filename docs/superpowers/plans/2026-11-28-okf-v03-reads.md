# OKF v0.3 reads (O7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GECKO reads OKF frontmatter by v0.3's consumer rules, and already-synced databases pick
the change up on their next sync.

**Architecture:** All reading happens in `core/gecko-engine/src/okf/` (`parser.rs`, `provenance.rs`).
The sync (`syncer/bundle.rs`) already writes whatever the parser produces, so it is untouched
except for the hash it compares. Three `@doc` strings change in `core_schema.tql`, each with a
`CORE_MIGRATIONS` `redefine`.

**Tech Stack:** Rust 2024, serde_yaml, chrono, TypeDB 3.15 (integration tests), cargo-nextest.

**Spec:** `docs/superpowers/specs/2026-11-28-okf-v03-reads-design.md`. Read it first: it holds
every rule and its reason. The OKF v0.3 spec is
`~/.claude/plugins/marketplaces/open-knowledge-format/SPEC.md` (commit `527e81a`).

## Global Constraints

- The v0.3 rules apply whatever `okf_version` a bundle declares.
- A value GECKO can't read is warned about by file, key and value, kept in `metadata-json` as
  written, and never invented. The only exception is the `stale-after` sentinel
  `1970-01-01T00:00:00Z` (`DateTime::UNIX_EPOCH`).
- `engine`, `timeout-ms` and `scopes` keep their current rules exactly.
- Comments are greenfield (CLAUDE.md): no "used to", no plan tags, no "v0.2" where a rule is
  version-neutral.
- Gates before every commit, each checked by its own exit code, never through a pipe:
  `cargo fmt --all -- --check`;
  `cargo clippy --workspace --exclude js-sandbox --no-default-features --all-targets -- -D warnings`;
  the same with `--features cyber`.
- Tests run one at a time. TypeDB 3.15 runs on `127.0.0.1:1729`. Never touch the database named
  `gecko`.
- Stage named paths only (never `git add -A <dir>`). End each commit message with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Don't edit `core/gecko-engine/tests/okf_v02/` or anything under `*/tests/fixtures/`.

## Review Focus

Inputs the spec implies that a person would hit, most likely first. Each one's test is added to
the task named.
1. **A file saved with a UTF-8 BOM before `---`.** Today it fails loudly; under the strict
   delimiter rule it would vanish quietly. Expected: the BOM is ignored and the file reads as
   before (Task 1, `a_bom_before_frontmatter_is_ignored`).
2. **A near-miss delimiter.** A blank line before `---` is not a concept, and it warns rather
   than vanishing quietly (`a_near_miss_opener_is_skipped_with_a_warning`). Trailing spaces or
   tabs on either delimiter are tolerated, so a synced concept is never silently
   garbage-collected over invisible whitespace (`delimiters_are_exact_lines`). Both tests are in
   Task 1.
3. **CRLF line endings** throughout a concept. Expected: reads exactly like LF (Task 1, in
   `delimiters_are_exact_lines`).
4. **RFC 3339's lowercase `t`/`z` and fractional seconds** in `generated.at`. Expected: accepted,
   since RFC 3339 allows them (Task 3, `rfc3339_variants_are_accepted`).
5. **A bundle path given through a symlink**, such as `gecko sync ./link-to-bundle`. Expected:
   the bundle reads normally; only symlinks *inside* it are skipped (Task 2,
   `a_symlinked_bundle_root_is_read`).
